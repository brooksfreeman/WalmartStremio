# Which files do what?

[Back to README](../README.md) · [Installation guide](INSTALLATION.md)

The repository includes a working PC-hosted app and the research that led to it.
Research tools may be executable, but that does not make them installation steps.
The installation guide lists every command needed for the supported setup.

## Current app: files used for setup and everyday operation

| File or group | Purpose |
| --- | --- |
| `scripts/tvctl.py` | Pairs with the TV using its displayed PIN and makes certificate-pinned local control requests |
| `scripts/prepare_stremio_tv.py` | Applies the TV interface adaptations to the pinned Stremio Web checkout |
| `client/TVRemoteBar.js` | Playback controls designed for the TV remote |
| `client/TVSearchKeyboard.js` | Search keyboard usable with directional buttons |
| `client/TVRuntime.js` | TV navigation and browser behavior adjustments |
| `client/TVAddonManager.js`, `client/TVAddonImport.js` | TV-side add-on operations and optional import support |
| `scripts/serve_lab.py` | Hosts the built frontend and local control endpoints on port 8099; also contains diagnostic endpoints |
| `scripts/stremio_service.py` | Downloads, checks and prepares the pinned media engine, then runs it on port 11470 |
| `scripts/service_entry.py` | Starts each background component and sends its output to private logs |
| `scripts/install_services.py` | Generates and installs the three systemd user-service files for this PC |
| `scripts/watch_power.py` | Watches TV state and opens Stremio when the configured WatchFree or power transition occurs |
| `scripts/home_navigation.py` | Shared app-state matching and shortcut configuration; also retains older Home/HDMI helper code |
| `scripts/configure_home.py` | Saves the shortcut preference; use `enable-watchfree` for the current setup |
| `scripts/observe_home.py` | Reads app/input changes to check whether a TV reports the expected WatchFree app ID |
| `scripts/open_stremio.py` | Opens the catalog or streaming-server settings on the TV |
| `scripts/tv_control_panel.py` | The GTK desktop app named **Stremio TV** |
| `scripts/addon_manager.py` | Validates add-on links and coordinates TV-confirmed add-on operations |
| `scripts/server_bandwidth.py` | Measures estimated TCP traffic for the hosting services |
| `scripts/install_desktop_control.py` | Creates the desktop and Applications shortcuts |
| `scripts/server_awake.py` | Optional power-settings helper for the tested GNOME-schema/Xfce setup; not required on every desktop |
| `config/systemd/vizio-stremio-awake.service` | Optional sleep blocker; independent of the three hosting services |
| Other `config/systemd/*.service` files | Examples regenerated by `install_services.py`; shipped paths/addresses are placeholders |
| `config/icons/stremio-tv.svg` | Desktop app icon |
| `web/vendor/hls.min.js`, `web/vendor/hls.js-LICENSE` | Player library used by the frontend build and its license |
| `web/launcher.html`, `web/launcher.css`, `web/launcher.js` | Optional PC-hosted app launcher; also used by the on-screen player Home action |
| `scripts/launcher_apps.py` | Native-app descriptors shared with the web server/launcher |
| `tests/test_desktop_addons_bandwidth.py` | Local regression tests; they do not contact a TV |

**The full Stremio app is not stored in `web/`.** Installation downloads its pinned
source to `.private/stremio-tv-src/`, copies in the `client/` additions, and builds
it there. The server exposes only that checkout’s `build/` directory at `/stremio/`.
The downloaded media engine lives separately under `.private/`.

## Diagnostic and research code

These scripts and pages were used to investigate TV behavior. Some can launch
diagnostic pages, change temporary state, or perform guarded experiments. Read
their associated research notes before using them; they are not setup shortcuts.

| Files | Investigation |
| --- | --- |
| `scripts/capture_from_physical_home.py` | Home-button observations |
| `scripts/disconnect_test.py`, `scripts/test_tv_local_launch.py` | Earlier launcher behavior with PC helpers stopped |
| `scripts/inspect_native_installation.py`, `scripts/open_native_probe.py`, `scripts/probe_loopback_origin.py` | TV runtime/browser/native-interface inspection |
| `scripts/native_home_policy.py` | Guarded native Home routing experiment; not required or established as a Home replacement |
| `scripts/inspect_utv.py`, `scripts/check_qterics_keys.py` | Offline firmware-format and key-trial research |
| `scripts/inspect_vendor_oss.py`, `scripts/inspect_vendor_oss_nested.py`, `scripts/extract_vendor_oss_selected.py` | Manufacturer source-archive inspection |
| `scripts/inspect_vendor_sdk_archives.py`, `scripts/extract_vendor_sdk_libraries.py` | SDK/interface research |
| `web/loopback-*.js`, `web/local-runtime.*` | Browser/native-bridge diagnostic pages and scripts |
| `web/hello.*`, `web/player.*`, `web/style.css`, `web/test-captions.vtt`, `web/addon/` | Test pages, playback checks and sample add-on data; not the main Stremio application |

## Local files that are not published

`.private/` is created during setup and contains credentials, the TV certificate
pin, source/build downloads, the media engine, add-on settings/backups and logs.
It is excluded from Git. `.env`, `.tv_auth`, firmware archives and raw device
captures also stay out of the public repository. Do not upload them for support.
